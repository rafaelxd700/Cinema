# CineMax — Site de Cinema

## Sobre o projeto

O CineMax é um site desenvolvido como atividade acadêmica para a disciplina de desenvolvimento web, utilizando HTML e CSS. O objetivo é criar uma interface de cinema moderna, organizada, acessível e responsiva, permitindo que os usuários conheçam os filmes em cartaz, consultem detalhes, visualizem sessões e conheçam as opções de ingressos.

## Objetivos

- Desenvolver páginas web utilizando HTML e CSS.
- Criar telas conectadas por meio de uma navegação simples.
- Aplicar conceitos de UX (Experiência do Usuário) e UI (Interface do Usuário).
- Utilizar boas práticas de acessibilidade e responsividade.
- Trabalhar em equipe utilizando o Git e o GitHub.

## Páginas do site

O projeto é composto pelas seguintes páginas:

- **Início (`index.html`):** apresentação do cinema e destaques.
- **Filmes (`filmes.html`):** exibição dos filmes disponíveis.
- **Detalhes (`detalhes.html`):** informações sobre um filme.
- **Sessões (`sessoes.html`):** consulta aos horários das sessões.
- **Ingressos (`ingressos.html`):** apresentação dos tipos e preços de ingressos.
- **Contato (`contato.html`):** informações e formulário de contato.

As páginas possuem links de navegação para facilitar o acesso às diferentes áreas do site.

## Conceitos de UX e UI utilizados

- **Consistência visual:** utilização de cores, fontes e elementos visuais padronizados.
- **Hierarquia visual:** títulos, botões e informações organizados por importância.
- **Navegação intuitiva:** menu para facilitar a localização das páginas.
- **Organização do conteúdo:** informações separadas em seções e cartões.
- **Identidade visual:** tema escuro com detalhes em vermelho, inspirado na experiência de cinema.
- **Facilidade de uso:** botões e links com identificação clara.

## Acessibilidade

O projeto busca melhorar a acessibilidade por meio de:

- Contraste entre o texto e o fundo.
- Textos organizados em títulos e seções.
- Links e botões com identificação clara.
- Textos alternativos em imagens, quando aplicável.
- Navegação por teclado e indicação visual de foco, quando implementadas.

## Responsividade

O layout utiliza CSS responsivo para adaptar a apresentação do site a diferentes tamanhos de tela, como computadores, tablets e celulares.
